I’m a **17-year-old front-end designer and developer** in Lagos, Nigeria. I like thoughtful interfaces, useful tools, and the occasional project that turns out to need a compiler.

### Things I’m building

- **[Reeda](https://github.com/thekzbn/reeda)** — a reading workspace that keeps PDFs and notes together, so reading and thinking can happen side by side.
- **[C++ Core](https://github.com/thekzbn/cpp-core)** — an interactive C++ tutorial that runs in the browser, with local compiler support.
- **[Bob](https://github.com/thekzbn/bob)** — a small language and compiler that turns `.bob` files into web pages.
- **[patch.md](https://github.com/quingdotdev/patch.md)** — an early prototype exploring safer, repairable app extensions. Still an experiment, not a finished framework.
- **Geng Shii** — a terminal-style adventure game built around stateful storytelling. More on [my portfolio](https://www.thekzbn.name.ng).
